# CyberShield VPS Landing Page

A premium, modern SaaS landing page for the "CyberShield VPS" security plugin.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features Included
- Sticky, translucent navigation bar.
- Hero section with glowing 3D/animated illustrations.
- Trust bar with auto-incrementing threat block rate.
- Interactive Pricing Configurator utilizing React state and Framer Motion spring physics.
- Responsive features grid with hover animations.
- Modern color scheme mimicking high-end server products.
